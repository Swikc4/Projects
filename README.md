A portfolio of academic and personal projects by **Swikriti KC**, a Computer Information Systems student at Baruch College concentrating in Data Analytics and minoring in Mathematics.

## Featured Work

### NYC Motor Vehicle Collision Fatality Analysis
**Python · pandas · scikit-learn · Logistic Regression**

Team analysis of NYC motor-vehicle collision data examining whether Ford vehicle involvement independently predicts fatal crash outcomes after controlling for driver, vehicle, and time-based factors.

**Highlights**
- Cleaned and prepared collision records for analysis.
- Engineered binary features including fatal outcome, vehicle characteristics, driver factors, and time-based indicators.
- Used logistic regression to model fatal-crash outcomes.
- Evaluated model results and interpreted influential variables.
- Worked with a team to communicate findings and limitations.

### Music Listening Database Application
**Python · SQL · SQLite · Git/GitHub**

Team database project modeling artists, tracks, playlists, and playlist-track relationships with a normalized relational schema.

**My contribution**
- Implemented SQL query functions for playlist-track retrieval, unassigned tracks, most-added tracks, and playlist-duration analysis.
- Used `JOIN`, `LEFT JOIN`, `GROUP BY`, `COUNT`, aggregates, and ordering.
- Tested the query module independently with an in-memory SQLite database.
- Contributed through a Git branch and pull-request workflow.

[View my merged project contribution](https://github.com/ProfessorPatrickSlatraigh/mp02-music-starter/pull/29)
