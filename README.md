# Data Analytics and Machine Learning Projects

A portfolio of academic and personal projects by **Swikriti KC**, a Computer Information Systems student at Baruch College concentrating in Data Analytics and minoring in Mathematics.

## Featured Work

### [NYC Motor Vehicle Collision Fatality Analysis](https://github.com/Swikc4/nyc-collision-fatality-analysis)
**Python · pandas · scikit-learn · Logistic Regression**

Team analysis of NYC motor vehicle collision data examining whether Ford vehicle involvement independently predicts fatal crash outcomes after controlling for driver, vehicle, and time related factors.

**Highlights**
- Cleaned 89,102 raw collision records and prepared a 70,272 observation modeling dataset.
- Engineered features for fatal outcomes, vehicle characteristics, driver factors, and time based conditions.
- Used logistic regression to model fatal crash outcomes.
- Evaluated coefficients and statistical significance and presented findings with a four person team.

### [Music Listening Database Application Contribution](https://github.com/Swikc4/music-listening-database-contribution)
**Python · SQL · SQLite · Git/GitHub**

Three person team database project modeling artists, tracks, playlists, and playlist track relationships.

**My contribution**
- Implemented four SQL query functions for playlist track retrieval, unassigned tracks, most added tracks, and playlist duration analysis.
- Used `JOIN`, `LEFT JOIN`, `GROUP BY`, `COUNT`, aggregates, and ordering.
- Tested the query module independently with an in memory SQLite database.
- Contributed through a Git branch and pull request workflow.

### [Press Release to Plot Industry Comparison](https://github.com/Swikc4/press-release-to-plot)
